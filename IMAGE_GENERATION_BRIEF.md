# AFTER THE VOWS — image generation brief

Replace the temporary PNGs in `assets/` with generated images using the **same filenames**. Keep the PNG format. The site already points to these paths, so replacing a file does not require code changes.

The current PNGs are labeled placeholders, not photographs. There are no SVG assets in this project. The venue wayfinding diagram is built from HTML and CSS and does not need an image.

## Shared art direction

- Photorealistic premium fashion-wedding editorial; cinematic evening event, not a garden-wedding template.
- Deep controlled shadows, warm champagne highlights, natural skin texture, subtle film grain.
- Restrained Almost Black, ivory, champagne and burgundy palette. Avoid strong red color casts.
- No text, lettering, logos, watermarks, borders, collages or graphic layouts inside generated images.
- The fictional adult couple is consistent in every couple portrait: Anastasia, with dark chestnut hair in a sleek low bun and a minimalist ivory architectural satin gown; Kirill, with short dark hair in a classic black tuxedo, white shirt and black bow tie.

## 01 — `hero-couple.webp`

- **Section:** 01 — Hero.
- **Description:** The key cinematic portrait establishing the event and the couple.
- **Aspect / size:** 16:9; 2400 × 1350 px or larger.

- **Palette / finish:** Almost Black, warm stone, champagne highlights, restrained burgundy, natural skin, subtle film grain.

## Generation order and quality checklist

1. Generate and approve `hero-couple.webp` first.
2. Generate `venue-exterior.webp`, `venue-interior.webp`, `editorial-details.webp` and `dress-code-editorial.webp`.
3. Generate the four gallery frames using the approved hero as the reference for each.
4. Export every image as PNG, crop to the aspect ratio above, and save it under the exact filename in `assets/`.
5. Match exposure, black point, champagne highlights and burgundy saturation across the set. Avoid an aggressive red filter.
